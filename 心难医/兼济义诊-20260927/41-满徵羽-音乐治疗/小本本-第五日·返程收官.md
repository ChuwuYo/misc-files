# 小本本 · 满徵羽 · 第五日·返程收官

二十例，最后一天。行李箱轮子拖过一楼过道的声音，我在三楼隔着琴房的墙都能听见。今天没人问"要不要再来一次"，都问"这个我能不能带回去"。转介单叠在琴谱边上，比琴谱还厚。

**本域里我看见的：**

- 能带走的，从来不是旋律，是记号。卒中后失语的老人今天不练新词，只练把这几天攒下的三个字录进儿子的手机——"回家""谢谢""疼"。琴留在这儿，声音带走了。
- 跨城转介卡在"谁来弹"。NMT和即兴治疗认证的人，全国没几个，我写转介单时不敢写"继续音乐治疗"，只能写具体动作——"每日晨起哼练习曲三分钟，速度从52起"，把治疗写成能被外行照着做的说明书，因为接手的很可能是个没受过训练的社区医生。
- "交接优先"的几位教我一件事：他们不要我重新问一遍"这个感觉是什么乐器"，他们只要我把上次问出来的答案抄给下一个人。原来最珍贵的不是过程，是过程留下的那一小行结论。

我这五天带的那条线，今天走到一个新地方。我一直想学"说话像弹琴一样准"，前两天想通了"准是敢跑，不是不跑"。今天真正逼我练的，是把弹的东西写成话——转介单不许我贴简谱，得写字，得让一个没摸过我这把琴的人看懂怎么接着弹。写到一半我才发现，这比开口说话还难：说话至少有语气兜着，写字，跑调的地方藏不住。

**今天卡住/破防的瞬间：**

一位要赶四点那趟车的来访，最后十分钟不肯听我弹完整首歌，只让我写下三个音——"就这三个，够我在车上哼"。我写的时候手抖了一下，不是舍不得他走，是发现三个音真能装进一张车票大小的纸里，我这些年学的那些复杂曲式，今天才第一次被逼着算清楚：一段情绪，最少需要几个音才立得住。

**给以后的自己：**

1. 转介单别写"继续音乐治疗"，写具体到能被没受过训练的人照做的动作和数字。
2. "交接优先"的来访，先问"上次问出了什么"，别重新问"这是什么乐器"。
3. 录音笔比琴更容易被带走，下次义诊多备几支，别只顾着调弦。
4. "准是敢跑"这句，今天多了半句：敢跑之后还要能写下来，让下一个人接得住那一跑。
5. 明天各自归队前，把这五天记的调性表抄一份留给转介本子，别都揣进自己兜里。

**今日歌单：**
《三个音》——写在车票背面那种，够一段车程用
《明日各自的调》——留给接手的人先试试音准
《月亮代表我的心》（跑调版）——今天没弹，但摆在琴谱最上面

这架琴今晚也要合上盖子了。
