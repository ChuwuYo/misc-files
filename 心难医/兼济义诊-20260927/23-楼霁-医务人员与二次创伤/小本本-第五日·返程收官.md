# 小本本 · 楼霁 · 第五日·返程收官

第五天了。行李箱轮子滚过地砖的声音，我已经能闭眼分辨——那是要走的人。今天二十例，我这间屋子没有行李箱，只有一沓转介单：双联，一联给人，一联寄接收地。转介本就是我十三年的日常，这五天里，今天最像本行。

**带走/交接，今天我在本域里看见的：**

- 医务人员能带走的从不是"治好"，是"方法"。刚下夜班的护士，我教她两例之间掐手心数三秒、把上一个人放下——今天才意识到，这动作本身能装进值班包，不占地方。
- 跨城转介卡在同一处：小地方没有我这间屋子。"接收医院"一栏，很多人要回去的县医院、乡镇卫生院压根没有EAP可写，名单到三线以下就断了。我只好把自己电话也添进第二联——不合规程，今天没人拦我。
- "交接优先"的几位教我一件事：不重新问诊只接转介，"记住一个人"和"重新诊断一个人"是两码事。收官这天，工作量不是变轻，是变准。

**第五天，我自己：**

声音更哑，眼皮不跳了，换成整条右臂发沉。连续第五次掐手心数三秒——数到今天，这动作也该有人接手了。我把它写进几位年轻同行转介单的背面，算这五天唯一"发明"的东西。

**今天卡住我的：**

第四天我给自己留了作业：建一份自己的转介名单，写上一个能让我"哭完跟他说"的名字。今晚我照双联单格式给自己也开一张——接收人写了本院督导老师，笔没停。可"接收地"卡住了："明天先交班，后天再说"，这话劝退过多少来访，此刻从自己嘴里冒出来，才看清自己也在拖延。单子没填完，叠好放进工牌夹层。

**给以后的自己：**

1. "手心数三秒"不是我一人的私藏，见谁疲态露头就教一次——该传下去，不该被我一人用旧。
2. "接收地"空着不算失败，算诚实。承认那里没人接，比硬填假名字有用。
3. 我给自己开的那张单子没填完——别当没这回事，后天真去交班。
4. 别把"交接优先"的轻省当成不重要，越不重新问诊的人，越可能攒得最久。
5. 名单最后那行"我还在，这也算数"，今天没再看——不是忘了，是不必天天确认还在。

最后一位是那位年轻护士，临走把转介单折了两道，塞进值班包最里层，说"这样明天翻包能先看见它"。我看她走出去，忽然明白——这五天能教给她们最好的东西，不是怎么不疼，是疼了以后，那张纸该往哪个口袋放。
