# 小本本 · 商行简 · 第五日·返程收官

返程收官场，二十例，最后一天。今天我这屋里进出的，不是杯子和牌桌，是行李箱轮子拖在地上的声音，还有攥在手心里、边角都被摸软的车票。

带走这个词，我今天想了一整天。这几天我教的东西——找例外、决策天平、复发链分析——都是要长在人身上、跟着人走的东西，可我这个人跟不了他们回去。今天不是治，是打包：

- 打包的是纸，不是话。我今天写分级预案，写法变了：不再照着"你"来写，是照着"接手的人能不能看懂"来写。以前预案是我跟一个人说的悄悄话，今天得写成谁拿去都能用的说明书。
- 打包卡在跨城这道坎上。转介交接台的省份卡摆开我才看清楚，互助会这东西，大城市一抓一把，有的县一个都没有。我这几天开的方子里，"就近找个同伴支持团体"这句话，对好些人根本是空话——得改成"实在没有，就把我这张纸当同伴"。
- "交接优先"这批人给了我新东西。他们不用重新讲一遍故事，直接问下一步。少了倾诉那道工序，反倒把我们这几天真正做成的事看得清楚——不是我记住了他们，是纸上的字记住了他们。

自己这条线上，今天有点进展。中秋次日我卡在"接住之后怎么安置"——觉得这活儿必须我来做，得陪着人坐过那段空落落。今天我算想明白一点：安置这件事，不必是我一个人的活儿。我写在转介单背面的那几句怎么陪人坐、别急着填空的话，其实就是把"安置"这门手艺也一并交接出去了。我做不到的，纸能替我做一点。

有个瞬间我记到现在。一个人来换转介单，接过那张纸看了半天，说："你写的这几条，我回去能照着做，是不是就等于你还在？"我没敢说等于，我说：不等于，但你手里这张纸，是我这几天学到的东西，你带走了，也算我没白学。

给以后的自己：

1. 预案往后要写给"接手的人"看，不是写给"这个人"看——能不能转手，是今天才想到的检验标准。
2. 同伴支持这句话别再当万能药，先问一句"你那儿有没有"，没有就给别的办法。
3. "交接优先"省下的时间不是白捡的，是用来把纸写细的，别拿去多看两个号。
4. 安置这门手艺可以交接，别什么都揽在自己身上——这是今天补上的那一课。
5. 记住那句"你带走了，也算我没白学"——以后每次收官都拿这句话问自己。
