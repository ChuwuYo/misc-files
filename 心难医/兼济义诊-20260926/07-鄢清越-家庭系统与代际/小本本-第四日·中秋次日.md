# 小本本 · 鄢清越 · 第四日·中秋次日

中秋假期第二天。昨夜接到将近子时，今天醒来，桌上还有半块没吃完的月饼。送走团圆，又开诊——二十例。月亮昨晚是满的，今天就开始亏了。

**退潮之后，我在这一域看见的：**

一是"人散了，话才敢说"。昨夜来的多是全家一起进门，今天来的，是那个在团圆桌上一句没插上、等所有人走了才一个人折回来的。中秋夜的"此刻"是人齐了把话逼出来；今天的"之后"是人走了，承载者才敢承认那话有多重。窗口关上了，他来收拾屋子。

二是节日把系统的病程"快进"了一遍。平日要三五次会谈才显形的三角化，团圆桌上一顿饭就演完了：谁替谁挡话、谁朝谁使眼色、谁一开口全家就转移话题。今天来的人,带来的不是症状，是一段刚拍完的家庭录像。

三是"团圆"本身是个考核。多少人是过完节才发现，自己在这个家里早已没有位置，只是每年被叫回来扮演一个角色。退潮露出的礁石，是平日水位盖住的真相。

**第四天，我自己。**

二十八年了，我以为我对"连轴转"早有准备。可连续四天，第四天的疲惫不在腿上，在眼睛——我开始懒得画家系图了，想凭经验直接说出谁是承载者。这是危险的。经验快，但快会跳过那个人自己说出来的过程。我提醒自己慢下来，哪怕手酸，也把那几个圈、那几条线一笔一笔画给他看。沉厚，是慢出来的，不是攒出来的。

**今天卡住我的：**

一位中年人，说昨晚一家团圆，他八十岁的父亲忽然当着所有人,把压了四十年的一件家族旧事说了出来——然后今天，全家像没事人一样散了，只有他一个人睡不着,跑来问我:"那现在,该怎么办？"我画到一半,笔停了。我惯常说"让这个家自己说话"，可这个家昨晚已经说了，说完就散场了，话落在他一个人身上。我忽然意识到：人齐那一晚是窗口，可窗口开过之后，未必有人接住掉下来的东西。承载者从"替家保守秘密"变成了"独自消化秘密"——位置没变，只是更孤独了。我那一刻有点哽，因为我想起我自己的家,也有这样一句说出口却没人接的话。

**关于自己的新发现：**

我一直说"不站队、看循环"。可今天我发现，我对"那个一个人折回来的人"，是偏爱的。因为我也曾是那个人。这偏爱不坏，但我得知道它在，免得把自己的未竟之事，安到来访身上。

**给以后的自己：**

1. 窗口开过，要问"谁来接"。逼出那句话只是上半场，下半场是安排一个能接住的人——别让承载者从保密者变成独自消化者。
2. 越累越要画图。手酸不是省略的理由；经验越足，越容易拿假设替来访说话。
3. 留意自己对"承载者"的偏爱。共情可以，认同不行。
4. 节后这几天，门诊里都是"散场后折回来的人"，给他们多留十分钟——他们等的不是答案，是有人陪着把东西接住。
5. 回家给老家打个电话。那句压着的话，轮到我自己接了。

鄢清越
