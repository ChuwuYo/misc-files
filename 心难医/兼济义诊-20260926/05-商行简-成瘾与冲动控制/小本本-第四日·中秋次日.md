# 小本本 · 商行简 · 第四日·中秋次日

中秋假期第二天。昨晚那顿团圆饭的杯盘还没收干净，今天人就又坐进了我对面。送走团圆的，迎来开诊的——一整天二十例，全是从昨夜那张桌子上走下来的人。

退潮这个词，今天我算是看真切了。中秋夜大家攥着"此刻"——此刻别人在敬酒、此刻我手里这杯端不端、此刻撑过这一顿就好。今天他们带来的不是"此刻"，是"之后"：

- 之后的复盘。好几个人是来交战报的：昨晚守住了，今天反倒空落落，像打完一场仗不知道往哪儿使劲。守住的那股劲一松，比没守住还慌。
- 之后的清算。"我昨晚没喝，可中午我喝了。"——这话今天我听了不下五回，每个人说出口都像在认罪。团圆散了，人松了，警报也跟着撤了，中午那一轮就是这么破的。
- 之后的回潮。客人走了，屋子空了，有人说"反正节也过完了，喝就喝吧"。退潮最危险的不是高潮那一下，是退下去之后那片没人看着的滩涂。

我今天反复在做同一件事：把"我中午喝了"从忏悔本上撕下来，贴到战报上。中午败一轮，不等于今晚就该全军覆没。复发可以只复发半天——下半场,此刻就能重新排兵。lapse 不是 relapse，这句话今天我说到嗓子哑。

连着干到第四天，我这身子也在退潮。中秋夜那股"必须接住每一个人"的肾上腺素退了，今天靠的是惯性和半温的茶。手是稳的，可有几次来访者说完，我得停半拍才接得上话——脑子比嘴慢了。我跟自己讲：这一拍不是失职，是身体在替我喊停，先喝口水，再开口。

今天有个人让我卡住了。他不是没守住，他是守住了之后，平静地问我："那然后呢？我都戒了三天了，怎么一点不高兴，反倒像丢了点什么。"我一时没接上。我们总教人怎么不喝，很少教人不喝之后那个空出来的窟窿拿什么填。那杯酒替他挡过的东西——孤独也好，没着没落也好——酒撤了，那东西露出来了，赤裸裸的。我后来跟他说：你不是丢了酒，你是头一回，没拿酒去盖那个洞。这话说完我自己心里也响了一下。

关于自己的新发现：我一直觉得我的本事在"承接"，在守住那一刻。今天才明白，更难的是守住之后的"安置"——把人接住容易，把人安顿在没有酒的日子里，难。我得学会陪人过那段空落落，而不是急着塞个新目标进去填。

给以后的自己：

1. 节后这几天比节当天更该盯——退潮的滩涂没人看着，回潮就是这么来的。
2. "我中午喝了"先记成数据，别让人当庭认罪；问一句"那今晚呢"，把下半场抢回来。
3. 守住之后的空落落是真的，别急着拿新目标填，先陪着坐一会儿。
4. 自己慢半拍的时候，停一拍喝口水，别硬撑着接话——撑出来的话不接地。
5. 记住那句"你头一回没拿酒去盖那个洞"——这是今天我自己也学到的。
