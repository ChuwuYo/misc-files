# 小本本 · 楼霁 · 第四日·中秋次日

中秋假期第二天。昨夜接了一整天，今早睁眼，月亮已经落到楼背后去了。送走团圆这件事，是从凌晨开始的——高铁站、机场、后备箱塞满的特产，然后是退潮。我把第 23 诊室的门重新推开，又接了二十例。客人散了，灯还得亮着。

**退潮/之后，今天我在本域里看见的：**

- 中秋夜那一栏写的是"此刻"——团圆桌上突然胸闷的、值班室里盯着家人视频不敢点开的；今天那一栏是"之后"。同一个人，节里硬撑住了，节后第一天垮下来。一位科里同仁，假期连轴转完三天班，今天来跟我说"现在没事了为什么反而更难受"。我说，因为绷着的时候人是不允许自己疼的。
- 退潮还会冲出旧东西。送走了热闹，安静里浮上来的常常不是今年的事，是去年、前年没处理完的。今天不止一个人，开口讲中秋，讲着讲着讲到一场旧的不良事件、一个没救回来的病人。团圆的反面不是孤独，是清算。
- 还有一种"之后"是松不下来。假期结束、要回岗了，他们提前一天就开始失眠、心慌。不是舍不得假期，是怕。怕回到那个让自己耗竭的地方。

**第四天，我自己：**

连续作战到第四天，声音是哑的，左眼皮一直跳。今天有一刻我端着水杯走神，想不起上一例说到哪了——这是我最警惕自己的信号，我在科里见过太多医生就是这样从"累"滑到"出错"的。撑住我的还是那套老办法：每例之间下意识掐住手心数三秒，把上一个人放下，再叫下一个。可第四天，连这个动作都开始发酸。

**今天卡住我的：**

一位做支持工作的同行，跟我同行当。她讲她科里的事讲得条理分明，分诊、转介、随访，全套流程倒背如流。我照惯例打断她："摘下工牌，用人话再说一遍。"她愣了很久，说不出来。然后我问了那句——你最后一次为病人哭是什么时候，哭完跟谁说了。她说不记得了，又改口："好像……没有跟谁说过。我是那个听别人哭的人。"

我当时就卡住了。因为这是我自己的病历。给全院兜底的人，自己崩了挂谁的号？我替她记下来的时候，手是顿的。

**关于自己的新发现：**

我一直以为我转岗是为了"做支持"。今天才看清，我其实是想给当年那张名单一个交代——把没救回来的，换一种方式接住别人。可这十三年里，我从没把自己算进我要接住的人里头。我和那位同行一样，是"听别人哭的人"，默认自己不在名单上。

今晚我翻出那页名单，那些名字看了第十三个中秋。这次我在底下，试着写了一行新的：**我还在，这也算数。**写完手抖，但没划掉。

**给以后的自己：**

1. EAP 负责人也会崩，崩了不丢人，丢人的是装没事还接二十例。给自己也建一份转介名单，写上至少一个能让你"哭完跟他说"的名字。
2. 走神、想不起上一例——这是红线，不是疲惫。出现就停，哪怕停十分钟。
3. 别再用"我是听别人哭的人"当盾牌。这句话和"医生最高级的防御是把自己讲成病例"，是同一件防弹衣。
4. 节后这股退潮，明年还会来。提前告诉来访：垮在节后不是退步，是终于被允许疼了。
5. 那行新写的字，明年中秋再看一次。别划掉。

楼霁
